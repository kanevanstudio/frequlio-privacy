Frequlio 隱私權政策

生效日期：2026 年 11 月 23 日
適用範圍：Android App「Frequlio」（套件名稱 com.frequlio.wifitools）
開發者：KaneVan Studio

重點摘要

  • Frequlio 不需要註冊帳號。
  • Frequlio 不會把你的資料傳送到開發者的伺服器；開發者沒有為這個 App 架設任何伺服器。
  • Frequlio 沒有廣告，也沒有內建分析、追蹤或當機回報的第三方 SDK。
  • 診斷紀錄只存在你的裝置上，你可以隨時刪除。

1. App 會存取哪些資訊

附近的 Wi-Fi 資訊

使用 Wi-Fi 分析功能時，App 會向 Android 系統讀取附近 Wi-Fi 存取點的掃描結果，包含網路名稱（SSID）、存取點識別碼（BSSID）、訊號強度、頻率、頻道、頻寬與安全類型，以及你目前連線的 Wi-Fi 的同類資訊與連線速度。Android 11 以上還會讀取掃描結果中 AP 宣告的負載與能力（例如連線裝置數、頻道使用率、空間流數、漫遊與 PMF、WPS 等功能宣告）。

這些資訊只用來顯示在畫面上，並在裝置上計算頻道分布與頻道建議。App 不會把它們存檔，也不會傳送到任何地方；離開畫面或關閉 App 後不會保留。

唯一的例外是「訊號記錄點」：附近 Wi-Fi 掃描清單不會自動保存。你點選「記錄此位置」並按下儲存後，Frequlio 會在本機診斷歷史保留你輸入的位置名稱、目前連線的訊號強度、頻率、頻段與時間，不包含 Wi-Fi 名稱（SSID）、存取點識別碼（BSSID）、定位座標或附近的 Wi-Fi 清單。你手動匯出診斷歷史時，檔案會包含位置名稱。

目前網路的連線資訊

首頁會顯示 Android 系統提供的目前網路資訊：連線類型、系統的連線驗證狀態、IP 位址、DNS 伺服器、預設閘道、網路介面名稱、搜尋網域與 MTU。這些資訊只顯示在畫面上，不存檔、不傳送。

你輸入的診斷目標與診斷結果

執行 Ping、Traceroute、TCP 連線測試、DNS 查詢或 HTTP/HTTPS 診斷時，你輸入的主機名稱、IP 位址或網址，以及測得的結果（例如解析到的 IP 位址、耗時、HTTP 狀態碼、時間），以及測試使用的網路類型（Wi-Fi、行動數據或跟隨系統；不含 Wi-Fi 名稱），會存成一筆診斷紀錄，保存在你裝置上的 App 資料庫。連續監測只有在你停止後按「儲存摘要」時，才保存每個目標的統計摘要（送出與成功次數、失敗原因、最低／平均／最高耗時），不保存逐秒的結果。

執行一鍵完整診斷時，每一步的結果（例如通過或失敗、耗時中位數、HTTP 狀態碼）與你的路由器（預設閘道）的區網 IP 位址，同樣會存成一筆診斷紀錄。

HTTP/HTTPS 的網址只保存協定、主機與連接埠；路徑與查詢參數（網址中 ? 之後的部分）都會去除，因為兩者都可能含有權杖（Token）。系統回報的原始錯誤訊息不會保存。

App 設定

你選擇的主題模式（跟隨系統、淺色或深色）、App 語言（跟隨系統、繁體中文或英文），以及 Wi-Fi 頁的顯示設定（隱藏 BSSID、隱藏弱訊號網路）保存在裝置上。

2. 位置權限

Android 規定，App 必須取得「精確位置」權限，而且裝置的定位服務必須開啟，才能讀取附近的 Wi-Fi 清單。Android 這樣規定，是因為附近的 Wi-Fi 資訊在技術上可能被用來推估裝置所在位置。

Frequlio 只把這項權限用於讀取 Wi-Fi 掃描結果。App 不會向系統要求你的定位座標，不會推算、保存或傳送你的位置，也不會在背景使用這項權限。

App 只會在你進入 Wi-Fi 分析頁並按下授權按鈕時請求這項權限。不授權仍然可以使用其他功能。你可以隨時在 Android 的系統設定中撤銷授權。

3. App 會送出哪些網路請求

只有在你主動執行診斷時，App 才會送出網路請求：

  • Ping：向你輸入的主機或 IP 位址送出 ICMP Echo（回應請求）封包，並等待回應。
  • 連續監測：對你加入的每個目標（最多 5 個），每秒送出一個 ICMP Echo 封包或建立一次 TCP 連線，直到你停止，最長 30 分鐘；只在 App 開著、這個畫面顯示時執行。
  • Traceroute：向你輸入的目標送出存活時間（TTL）逐次遞增的 ICMP Echo 封包，沿途每一台路由器都可能看到這些封包並回報。紀錄會保存沿途回報的路由器位址。Android 11 以下改用系統內建的 ping 指令送出同樣的封包。Android 10 以上預設還會透過這次測試所用網路的 DNS 伺服器，反查這些路由器位址的名稱（可在 Traceroute 頁關閉「查詢主機名稱」），查到的名稱會與位址一起保存。
  • TCP 連線測試：與你輸入的主機及連接埠建立 TCP 連線，隨即關閉。
  • DNS 查詢：透過 Android 系統，向你目前網路設定的 DNS 伺服器查詢你輸入的網域（Android 10 以上也可查 MX、TXT 等記錄類型，或以 IP 位址反查名稱）。
  • 與 Google 公共 DNS 比較：只有你在 DNS 查詢結果下方按下「與 Google 公共 DNS 比較」時，才會以 DNS-over-HTTPS 把剛才查詢的名稱與記錄類型送到 Google Public DNS（dns.google）。Google 會收到這些內容，也看得到你的連線 IP；依 Google Public DNS 的隱私權說明，含 IP 的暫存紀錄通常在 24 至 48 小時內進入刪除流程，處理安全或濫用事件時可能保留更久，另有移除 IP 的抽樣永久紀錄。比較結果只顯示在畫面上，不存入歷史紀錄。已知的本機及內部名稱（例如 .local、私有 IP 的反查）不會送出。
  • 全球 Ping：只有你在「全球 Ping」按下「開始測試」時，才會把你輸入的目標（網域或 IP 位址）與所選地區送到 Globalping（api.globalping.io），由該地區的 Globalping 節點對目標送出 ICMP Ping，測試不是從你的裝置發出。Globalping 看得到你的連線 IP，也會依你的 IP 計算測試額度。依 Globalping 的條款，測試目標與結果是公開的：任何取得測試編號的人都能查看，Globalping 也可能發布、收錄或分析這些資料，他人轉存的副本無法刪除。請勿輸入內部或機密主機名稱；已知的本機及內部名稱與私有 IP 位址不會送出。結果只顯示在畫面上，Frequlio 不存入歷史紀錄。Globalping 如何處理這些資訊，依其條款與隱私權政策而定（globalping.io/terms）。
  • STUN 出口位址：只有你在「STUN 出口位址」按下「開始測試」時，才會透過你選擇的網路送出一個 UDP 請求到 Cloudflare 的 STUN 伺服器（stun.cloudflare.com），由它回報從外部看到的 IP 位址與 UDP 埠。Cloudflare 會看到這次連線的來源 IP 位址與 UDP 埠；它如何處理這些資訊，依 Cloudflare 的隱私權政策而定。結果只顯示在畫面上，同一次使用工具時會暫留前一次結果以便比較，離開工具即清除，不存入歷史紀錄。
  • HTTP/HTTPS 診斷：對你輸入的網址送出一次 HTTP 請求，讀取回應狀態，不下載內容，也不跟隨重新導向。
  • 一鍵完整診斷：先與你的路由器（預設閘道）建立 TCP 連線，再連到 Google 的固定測試目標：與 8.8.8.8 建立 TCP 連線、透過系統 DNS 查詢 connectivitycheck.gstatic.com，並對 https://connectivitycheck.gstatic.com/generate_204 送出一次 HTTPS 請求。Google 會因此看到你的 IP 位址；它如何處理這些資訊，依 Google 的隱私權政策而定。

這些請求的對象是你指定的目標、一鍵完整診斷的固定目標、你的網路所使用的 DNS 服務，你選擇比較時的 Google Public DNS，你使用全球 Ping 時的 Globalping，以及你使用 STUN 出口位址時的 Cloudflare。如同任何網路連線，目標服務、你的網路業者或中間的網路設備，可能因此得知你的 IP 位址等連線資訊；它們如何處理這些資訊，依各自的政策而定，不在本 App 的控制範圍內。

除了你主動執行的診斷之外，App 不會自行連線到任何伺服器。

4. 資料保存在哪裡、保存多久

  • 診斷紀錄與 App 設定只保存在你的裝置上。
  • 診斷紀錄最多保留 500 筆，超過時自動刪除最舊的。
  • 紀錄會一直保留，直到你刪除它、清除 App 資料或解除安裝 App。
  • App 已關閉 Android 的雲端備份與裝置間傳輸，診斷紀錄與設定不會經由這兩個管道離開你的裝置。

5. 資料分享

開發者不會取得你的資料，因此不會出售、分享或揭露給任何第三方。

App 提供把診斷紀錄匯出成 CSV 或 TXT 檔案的功能。匯出只會在你主動操作時發生，檔案會存到你在系統檔案選擇器中指定的位置。匯出後的檔案由你自行保管；在 App 內刪除紀錄，不會連同刪除已匯出的檔案。

你主動按下「複製」或「分享」時，該筆診斷結果會以文字複製到剪貼簿，或交給你在系統分享面板中選擇的 App。之後如何處理，依你選擇的 App 而定。

6. 第三方元件

App 使用開源函式庫來建構介面、進行網路連線與本機儲存（清單可在 App 的「設定 → 開源授權」查看）。這些函式庫在你的裝置上執行，不會為其開發者蒐集你的資料。

如果你是從 Google Play 安裝本 App，Google 可能依其自身的政策處理安裝與裝置相關資訊；那部分由 Google 的隱私權政策規範。

7. 你可以怎麼管理自己的資料

  • 刪除紀錄：在 App 的「工具 → 歷史」可逐筆或全部刪除，或在「設定 → 清除診斷紀錄」一次清除。
  • 撤銷位置權限：在 Android 的「設定 → 應用程式 → Frequlio → 權限」。
  • 刪除全部資料：清除 App 資料或解除安裝 App，裝置上由本 App 保存的資料會全部移除。

因為開發者不持有你的任何資料，所以沒有需要另外向開發者申請刪除的資料。

8. 兒童

本 App 不會蒐集任何使用者的個人資料，包含兒童。

如果 App 處理資料的方式有所改變，本政策會同步更新，並修改上方的生效日期。
